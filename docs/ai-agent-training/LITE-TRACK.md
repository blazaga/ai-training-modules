# Lite track: the same course in six modules (proposal, draft)

The full track has 11 chapters (00–10) and roughly **250 minutes** of labs. The lite track
covers the same ground in **6 modules** and roughly **170 minutes**, with the capstone as
homework. All lab times are estimates; nobody has run either track with an audience yet.

**What does not change:** the process. Every module that writes code still runs the same
loop, and every module keeps the same four lecturer slides (divider, _Run this_,
_Checkpoint_, _If you're stuck_):

```
spec → generate (nest-cli) → template → fill (agent, AI-FILL only) → verify (read the counts)
```

**What changes:** chapters are merged, and each module keeps **one** lab. The chapter
documents are the same for both tracks. A module points learners at the chapters it
covers.

## Modules

| 6 Secure MCP, then the capstone | ch09 + ch10 | rotate a secret mid-session, next call fails                                       | capstone moves to homework                                      | 20' |

## Why these merges

- **00 + 01:** the Docker setup has no lab of its own worth a slot. The first `pnpm verify`
  becomes the starting line for the resource lab.
- **03 + 04:** both are about identity. Devices exist so MCP can authenticate, and the
  rotation lab exercises the same "one 401 for every failure" rule.
- **05 + 06:** the envelope discussion is most concrete when learners read a real exchange.
  The raw `initialize` stands in for the lecture.
- **07 + 08:** both are about what goes over the wire and how a client sees it.
- **09 + 10:** device-key auth is the last technical step. The capstone takes an hour, so
  it moves out of the room.

## Lecturer deck

`slides/lab-companion-lite.pptx` and `slides/lab-companion-lite.md`: **32 slides** against
the full deck's 48. Both decks are generated by the same script
(`slides/build-lab-deck.mjs`). Where a module carries a chapter over unchanged (module 2 =
ch02, module 6 = ch09, and both of module 4's _Run this_ slides), the lite deck reuses the
full deck's slides, so a correction made once reaches both. Each module's divider notes
say which chapters it covers and what was cut.
