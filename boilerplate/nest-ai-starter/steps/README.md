# Workshop steps

One file per instruction, in order. The proctor says which step is next; you hand that one
file to your agent instead of typing the instruction out:

```text
Read steps/01-set-up.md and do what it says.
```

Your agent does that step only, then stops and waits, so the whole room moves one step at a
time. Do not point it at the whole folder.

| file                     | step                                  |
| ------------------------ | ------------------------------------- |
| `steps/01-set-up.md`     | Module 1 · Set the project up         |
| `steps/02-users.md`      | Module 1 · The users resource         |
| `steps/03-notes.md`      | Module 1 · Notes, with sharing        |
| `steps/04-mcp-server.md` | Module 2 · An MCP server on your data |

The slides show the same instruction text, with the file name, so you can also say it in your
own words.
